# Thumbnail Generator

Premium Thumbnail Generator untuk membuat thumbnail artikel Blogger dalam format **WebP 1200 × 675 px (16:9)**.

Dibuat dengan HTML, CSS, dan JavaScript murni tanpa framework eksternal.

## Features

- WebP output — 1200 × 675 px
- Live Preview
- Preview tab
- Custom background color
- Upload article image
- Custom post label
- Custom article title
- Multiple font family options
- Custom author
- Custom profile photo
- Custom blog name
- Circular profile image
- HaxorAI creator attribution
- Download directly as WebP
- Reset settings
- Responsive design
- Client-side processing — no server required

## Demo

[Thumbnail Generator](https://web.haxorai.com/thumbnail-generator)

## Usage

1. Open the demo.
2. Select the background color.
3. Upload the article image.
4. Enter the post label and title.
5. Select the desired title font.
6. Enter the author name.
7. Upload a profile photo if needed.
8. Enter the blog name.
9. Review the result in **Live Preview** or **Preview**.
10. Click **Download WebP**.

## Output

The generated thumbnail uses the following specifications:

- **Format:** WebP
- **Resolution:** 1200 × 675 px
- **Aspect Ratio:** 16:9
- **Quality:** 95%
- **Processing:** Client-side
